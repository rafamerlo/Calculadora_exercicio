## 💚 Sobre o projeto

Este projeto consiste no desenvolvimento de uma **calculadora**, criada como exercício prático para colocar em prática os conhecimentos adquiridos durante as aulas.

A proposta é trabalhar com operações matemáticas básicas e desenvolver uma interface simples, organizada e fácil de utilizar.

---

## ✨ Funcionalidades

* ➕ Adição
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão
* 🔢 Entrada de números
* 🧮 Realização de cálculos
* 🌱 Interface simples e intuitiva

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/rafamerlo/Calculadora_exercicio.git
```

### 2. Acesse a pasta

```bash
cd Calculadora_exercicio
```

### 3. Abra o projeto

Abra os arquivos do projeto no **Visual Studio Code** e execute a página HTML pelo navegador.
